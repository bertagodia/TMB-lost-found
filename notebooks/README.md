# Exploración

Guarda aquí los notebooks de análisis y comparación. La lógica que utilicen la CLI,
la API o las evaluaciones debe residir en `lostfound/` e importarse desde allí.

No subas salidas con datos personales, fotografías privadas, embeddings ni pesos.
Los resultados reproducibles se exportan a `reports/` y los índices a `artifacts/`.
