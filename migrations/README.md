# Migraciones de la base de datos

Área del equipo de base de datos. Una migración es un cambio versionado de las
tablas o relaciones que permite actualizar la base de todos los desarrolladores.

La futura configuración de Alembic y sus revisiones vivirán aquí. `versions/` está
reservado para esas revisiones. Todavía no hay migraciones ni esquema PostgreSQL.

Una vez se compartan migraciones aplicadas, los cambios posteriores deberán ir en
una revisión nueva, sin reescribir el historial utilizado por otros compañeros.
