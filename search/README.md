# Búsqueda y procesamiento de imágenes

Área para la búsqueda a partir de descripción, fecha, línea y sentido, y para
el procesamiento de fotografías de objetos y de imágenes opcionales de consulta.

Primero se establecerá una referencia textual. Después se comparará con búsqueda
multimodal cuando existan fotografías y datos suficientes. Las fechas y lugares
pueden ser imprecisos; el filtrado no debe descartar inadvertidamente el objeto.

Este componente devuelve candidatos para revisión. La similitud no acredita la
propiedad ni autoriza una devolución. La interfaz con backend se acordará antes
de integrar el motor. No hay implementación activa en esta carpeta todavía.
