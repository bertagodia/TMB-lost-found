# API e integración

Área compartida que conecta aplicación, base de datos y búsqueda. Acordad quién
se responsabiliza de implementarla antes de comenzar.

Aquí se añadirán los endpoints, validaciones, permisos y acceso a PostgreSQL.
Documentad los contratos de petición y respuesta para que cliente pueda avanzar
sin depender de detalles internos de la base de datos.

Por ahora no hay endpoints implementados ni una tecnología de servidor definitiva.
